# 사고 SOS 체크리스트

교통사고 직후 고객이 당황하지 않고 순서대로 처리하고, 담당 보험설계사(010-4003-0612)에게 바로 전화·문자할 수 있는 모바일 웹앱입니다.

- 큰 글씨·큰 버튼 (어르신도 보기 쉽게)
- 하단 고정 "설계사에게 전화" 버튼, 119·112 바로 걸기
- 보기 방식 선택: **한 장씩 보기**(기본, 밀어서 넘김) / 전체 보기
- 6단계 체크리스트 (휴대폰에 저장)
- 사고 정보 메모 → 설계사에게 문자로 한 번에 전송
- 홈 화면에 추가하면 오프라인에서도 열림 (PWA)

## 수정 방법
`app.html`을 고친 뒤 `sh build.sh`를 실행하면 `index.html`이 다시 만들어집니다.
내용을 바꿨다면 `sw.js`의 캐시 이름(`autoemer-vN`)도 올려주세요.
